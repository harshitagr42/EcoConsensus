# Dataset

Everything about the data used by EcoConsensus in one place: where it comes from, how it was created and
processed, how it is labelled, and its statistics. The data files themselves are **not in this repository** (their
licences do not allow redistribution); section 8 explains how to obtain and rebuild them.

Task: given the fixed claim **"Climate change and global warming is a serious concern."** and a Hindi or Bengali
comment, predict **favour (0)**, **neutral (1)** or **against (2)**.

## 1. Summary

| | Pol-NLI (climate subset) | SemEval-2016 Task 6 (climate target) | Evaluator's test set |
|---|---|---|---|
| Origin | Burnham et al., 2024, Hugging Face | Mohammad et al., 2016 | Course evaluator |
| Original language | English | English | Bengali, Hindi |
| Original labels | Binary entailment (0 / 1) | FAVOR / NONE / AGAINST, human-annotated | Not given to us |
| Our labels | 3 classes, refined with an LLM (silver) | Mapped to 0 / 1 / 2 (gold) | Predicted by the system |
| Hindi / Bengali text | LLM-translated (6 variants) | LLM-translated (6 variants) | Original |
| Source sentences used | 1,766 (1,676 train + 90 validation) | 564 tweets | 1,000 (500 Bengali, 500 Hindi) |
| Rows used (× 7 versions) | 12,362 | 3,948 | 1,000 |
| Role | Training (`train_base`), meta-model (`meta`), early stopping (`val`) | Held-out test (`semeval_test`), scored once | Final evaluation |

## 2. Sources and use of external data

The course did not provide a training dataset, so **all training and test data is external**, assembled from two
public English datasets and translated by us. No other data source was used.

### 2.1 Pol-NLI (primary training data)

- **What:** political texts recast as natural-language-inference pairs (premise, hypothesis, entailment), released
  with the Political DEBATE classifiers.
- **Links:** dataset <https://huggingface.co/datasets/mlburnham/Pol_NLI> · paper <https://arxiv.org/abs/2409.02078>
  ([PDF](https://arxiv.org/pdf/2409.02078)).
- **Purpose here:** training data for the two transformers (`train_base`), held-out data for the stacked meta-model
  (`meta`), and the early-stopping / prompt-check set (`val`).
- **How it was incorporated:** only the stance-detection rows about climate change were kept (section 4.1), the
  labels were turned into three classes (section 5), every sentence was translated into six Hindi and Bengali
  variants (section 4.3), then cleaned, deduplicated and split (section 4.4).

### 2.2 SemEval-2016 Task 6 (held-out test data)

- **What:** tweets annotated for stance toward six targets; we use the target "Climate Change is a Real Concern".
- **Links:** task page <http://alt.qcri.org/semeval2016/task6/> · dataset
  <https://www.saifmohammad.com/WebPages/StanceDataset.htm> · overview paper <https://aclanthology.org/S16-1003/> ·
  companion study <https://arxiv.org/abs/1605.01655>.
- **Purpose here:** a human-annotated, held-out test set (`semeval_test`), scored once after every model and prompt
  choice was fixed. Because its labels are human annotations, it is the most trustworthy score we report.
- **Also used in the method-comparison experiment** (section 7): a 300-tweet subset ranked the fine-tuning methods
  (head only, partial unfreezing, LoRA, QLoRA). Only the method choice carried over to the final training; no SemEval
  tweet was ever used to train the final models.

### 2.3 Evaluator's test set

- **What:** 1,000 comments for the final evaluation, 500 Bengali and 500 Hindi, in a file `input.csv` with the
  columns `Id` and `text`. We receive no labels.
- **Use:** only for the final predictions (`output_04.csv`, columns `Id` and `label`), made with the deployed system.
  It is never used for training or tuning.

## 4. Processing pipeline

### 4.1 Pol-NLI: filtering and label direction

Script: `scripts/data_sources/process_pol_nli.py` (run once; writes `data/raw/original/pol_nli_data/`).

1. Download `mlburnham/Pol_NLI` from Hugging Face and export the three splits to CSV.
2. Keep only rows whose `task` is `stance detection`.
3. Keep only rows whose hypothesis is "Climate change is a serious concern." or "Climate change is not a concern."
   (case and trailing full stop ignored).
4. Rewrite "Climate change is not a concern." as "Climate change is a serious concern." and **flip the entailment
   label** of those rows (0 ↔ 1), so every row refers to the same positive claim.
5. Drop the `dataset` and `task` columns.
6. Refine the binary labels into three stance classes with an LLM (Claude Opus 5.5, section 5.2). The test split of Pol-NLI is not used.

Result: Pol-NLI train **3,517** rows and validation **90** rows (columns `premise`, `hypothesis`, `entailment`,
`augmented_hypothesis`).

### 4.2 SemEval-2016 Task 6: filtering

Script: `scripts/data_sources/process_SemEval_2016_Task6.py` (writes
`data/raw/original/SemEval_2016_Task6/final_processed.csv`).

1. Keep only rows whose target is "Climate Change is a Real Concern" (564 tweets).
2. Drop the `Opinion towards` and `Sentiment` columns; keep `ID`, `Target`, `Tweet`, `Stance`.
3. Renumber `ID` from 1.
4. Labels are mapped later by explicit maps: `FAVOR` → 0 (favour), `NONE` → 1 (neutral), `AGAINST` → 2 (against).

### 4.3 Translation into Hindi and Bengali

Every English sentence of both datasets was translated **once** with an LLM (Claude Opus 5.5, chat) into six versions.
Each translated file is row-aligned with its English file, and each row keeps the label of its English source.
No human reviewed the translations.

| Language | Variant | Script |
|---|---|---|
| English | original | Latin |
| Hindi | pure Hindi | Devanagari |
| Hindi | Hindi code-mixed | Devanagari with English words |
| Hindi | Hinglish | Latin (romanised Hindi) |
| Bengali | pure Bengali | Bengali |
| Bengali | Bengali code-mixed | Bengali with English words |
| Bengali | Banglish | Latin (romanised Bengali) |

Example (one SemEval tweet, three of its versions): English *"We cant deny it, its really happening."*, Banglish
*"Amra eta deny korte pari na, eta sottii happen korche."*, Bengali code-mixed *"আমরা এটা deny করতে পারি না, এটা সত্যিই
happen করছে।"* (all labelled favour).

An earlier translation batch came out in the wrong language (`data/raw/translated/Bagheli/`). It is **never used**;
every script lists its input files explicitly so that folder cannot be read by accident.

### 4.4 Cleaning, deduplication and splits

Script: `src/training/prepare_data.py` → `data/processed/{train_base,meta,val,semeval_test}.csv`, `split_report.md`,
`manifest.json`.

1. Read the 7 versions of Pol-NLI train, Pol-NLI validation and SemEval from an explicit file list.
2. Check every translated file against its English file: same row count, same labels (and same IDs for SemEval).
3. Clean every comment with the one shared function `src/preprocessing.py` (section 4.5).
4. Pol-NLI train: remove the 64 sentence groups whose English text equals a validation or SemEval comment (78 of the
   90 validation sentences also occurred in train), then keep one source row per identical English text
   (**1,417 duplicate rows removed**; some sentences repeated about 100 times) → **1,676 unique source rows**.
5. Split Pol-NLI train into `train_base` (about 85 %) and `meta` (about 15 %), **grouped by source sentence** (all 7
   versions of a sentence land in the same split) and **stratified by label**, seed 42. Pol-NLI validation becomes
   `val`; SemEval becomes `semeval_test`. A check stops the script if a source sentence appears in two splits.

### 4.5 Text preprocessing (`src/preprocessing.py`, used everywhere)

| Step | Rule | Reason |
|---|---|---|
| Unicode | NFC normalisation | Devanagari and Bengali combining marks have several encodings |
| Dataset noise | Remove `#SemST`; remove a leading `RT` | Artefacts of the SemEval collection |
| Mentions | `@handle` → `@USER` | User names carry no stance and leak identity |
| Links | URLs → `URL` | Same |
| Hashtags | Drop `#`, keep the word | `#ClimateChange` carries meaning as a word |
| Whitespace | Collapse | Clean tokenisation |
| Kept on purpose | Emojis, case, punctuation, stop words, every script | They carry stance and sarcasm cues; the encoders are cased |
| Empty text | Flagged | Still predicted, but not scored and never sent to an LLM |

Model input is the sentence pair (claim, comment), truncated at 128 tokens (99th percentile: 58 tokens, so nothing was
cut).

## 5. Annotation scheme

### 5.1 Classes

| Id | Class | Definition |
|---|---|---|
| 0 | favour | The comment agrees that climate change or global warming is a serious concern |
| 1 | neutral (SemEval "NONE", problem statement "None") | Neutral, unrelated, or does not clearly express a stance |
| 2 | against | The comment disagrees with the claim |

This mapping is fixed everywhere in the code, the models and the prediction files. It matches the order of the
Pol-NLI entailment column (entailment, neutral, contradiction).

### 5.2 Labelling methodology

- **SemEval (gold):** the original human annotations of the SemEval-2016 task, mapped one to one (`FAVOR` → 0,
  `NONE` → 1, `AGAINST` → 2). We did not change any SemEval label.
- **Pol-NLI (silver):** Pol-NLI only has binary entailment labels. After the hypothesis rewrite and label flip
  (section 4.1), every row was reviewed with an LLM (Claude Opus 5.5, Anthropic, chat interface) against the class
  definitions above and given one of the three classes. These labels are derived by a model, not by human annotators, so they are treated as **silver** labels: used for training only,
  never for the final score.
- **Translations:** every Hindi and Bengali row inherits the label of its English source sentence (assumption:
  translation preserves stance).
- **Evaluator data:** unlabelled; predictions use the same 0 / 1 / 2 ids.

## 7. Method-comparison subset (experiment phase)

Before the final training, four fine-tuning methods were compared on a small SemEval subset
(`experiment/prepare_data.py`, `experiment/SETUP.md`):

- 300 tweets × 7 versions = 2,100 rows. **All 26 `against` tweets were kept** (about 9 % of the subset instead of about
  5 %), the rest sampled stratified by label.
- Split by tweet, stratified, 60 / 20 / 20: 180 / 60 / 60 tweets (1,260 / 420 / 420 rows), two seeds.
- Used only to choose the fine-tuning method (LoRA) and its settings. The final models were trained on Pol-NLI only.

## 8. Availability and reproduction

The data is not redistributed in this repository because of the datasets' licences; `data/` is git-ignored.
To rebuild it:

1. Pol-NLI: run `python scripts/data_sources/process_pol_nli.py` inside `data/raw/original/pol_nli_data/` (downloads
   the dataset from Hugging Face; needs `pip install datasets`). Refine the labels as in section 5.2.
2. SemEval: download the dataset from the official page, save the tab-separated file as
   `data/raw/original/SemEval_2016_Task6/unprocessed.csv`, then run
   `python scripts/data_sources/process_SemEval_2016_Task6.py` from the project root.
3. Translate both into the six variants (section 4.3) and save them under `data/raw/translated/{Hindi,Bengali}/` with
   the file names listed in `src/training/prepare_data.py`.
4. `python -m src.training.prepare_data` builds the cleaned splits and the Colab bundle.

## 9. Known limitations of the data

- Hindi and Bengali text is LLM-translated, not natural social-media writing; translation errors are possible.
- Pol-NLI's three-class labels are LLM-derived (silver); the neutral / stance boundary is noisy.
- Training sentences are political NLI premises, not tweets or YouTube comments (domain shift to SemEval).
- `against` is rare in SemEval (26 tweets, 182 rows), so Macro-F1 on `semeval_test` moves with a few predictions.
