1 Upload a CSV file

Evaluation file: input.csv with the columns Id and text (both are recognised automatically). The result is output_04.csv with the columns Id and label, in the same order and with the same Ids. Label key: 0 = favour, 1 = neutral, 2 = against (another spelling can be chosen before the run).

Other files work too: one column with the comments is needed; a true-stance column (for metrics), a claim column and an ID column are optional. You confirm every column and label value in the next step.
